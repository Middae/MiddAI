# Security Policy

## Reporting a Vulnerability

If you find a security issue in MiddAI, please report it through GitHub Issues or by contacting the project owner.

Please include:

- A clear description of the issue
- Steps to reproduce it
- Your operating system
- Any relevant screenshots or logs

## False Positive Antivirus Reports

MiddAI may be flagged by some antivirus tools because it is packaged as a Windows executable. This can happen with unsigned indie applications, especially those built with Python/PyInstaller.

For transparency, source files are provided in this repository where available.
